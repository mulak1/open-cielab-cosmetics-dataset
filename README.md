An open-access spectrophotometric reference dataset of **121 iconic Sephora, MAC, Clinique, Rare Beauty, Fenty, NARS, Dior, Charlotte Tilbury & Drugstore cosmetic shades** calibrated in **CIE $L^*a^*b^*$ (D65 6500K standard illuminant)**, paired with **CIEDE2000 ($\Delta E^*_{00}$) dupe distance matrices** and **12-Season Color Analysis harmony bounds**.

Maintained by the [**GlowIndex™ Colorimetry Lab**](https://www.glowindex.net/?ref=gh_open_cielab).
